# 03 关节电机控制状态机仿真

## 1. 任务完成内容
- 为四足机器狗添加关节电机控制程序，模拟真实电机输出特性
- 采用状态机架构实现两种控制模式：
  1. **阻尼模式**：所有关节电机处于阻尼状态，机器人自然放松下垂
  2. **站立模式**：从任意初始位置通过差值连续控制，驱动机器人平稳站立
- 支持键盘按键双向切换两种模式，切换过程平滑无突变
- 按6为站立模式；按7为阻尼模式

## 2. 环境与依赖
- 系统：Linux (Ubuntu)
- 仿真引擎：MuJoCo 3.14.0
- 编程语言：Python 3
- 依赖库：mujoco-python
